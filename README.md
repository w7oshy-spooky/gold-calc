# Gold Calculator

Bilingual Arabic and English calculator for gold jewellery pricing in Saudi riyals.

- Arabic: `index.html`
- English: `en.html`
- Shared calculation core: `gold-calculator.js`
- Shared UI behavior: `app.js`
- Tests: `tests/gold-calculator.test.js`

Run tests with Node.js 20 or newer:

`node --test tests/gold-calculator.test.js`

The app does not fetch a live gold price. Enter the current ounce price or a manual 24K gram price.
